# Auto Photo Organizer (一鍵式照片自動歸檔工具)

這是一個專為懶人與高效整理設計的智慧照片歸檔工具。完全不需要輸入任何繁複的命令列參數，只要將執行檔放進照片所在的資料夾中雙擊執行，就能自動將雜亂的舊照片按拍攝年月整齊分類！

---

## 🌟 主要特色

* **免參數、零設定（Zero-Config）：** 不需要手動敲指令指定來源或目標路徑，程式會自動偵測並以自身所在的資料夾作為掃描對象。
* **智慧時間判讀：** 優先讀取照片內建的 **EXIF 拍攝日期**；若該照片沒有 EXIF 資訊，則自動改用檔案的修改時間，確保所有照片都能找到對應的時間歸宿。
* **自動建立歸檔資料夾：** 執行後會自動在同層目錄生出一個名為 **`整理後照片`** 的新資料夾，並依據「年-月」（例如 `2023-05`）建立子資料夾，將照片安全複製進去。
* **未分類保護：** 針對完全找不到任何時間標記的特殊檔案，統一安全歸類至 `unclassified` 資料夾中，方便後續手動檢視。
* **獨立執行檔（.exe）：** 包裝成單一獨立的 Windows 執行檔，免安裝 Python 相關環境，雙擊即可一鍵完成！

---

## 🚀 如何使用 (Usage)

1. 將編譯好的 **`organize_photos.exe`** 檔案複製並放入裝有大量雜亂舊照片的資料夾中。
2. 用滑鼠**雙擊兩下**執行該程式。
3. 稍等片刻，程式會在同層目錄自動建立一個 **`整理後照片`** 資料夾，打開後所有年份與月份的相片已經通通排得整整齊齊！
